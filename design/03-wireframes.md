# StoryFlow-AI - Wireframes Iniciais

## 1. Objetivo

Este documento define a estrutura inicial das principais telas do StoryFlow-AI.

Os wireframes servem como guia de experiência do usuário antes da criação do design visual final.

# 2. Dashboard Principal

## Objetivo

Ser o ponto central de entrada da plataforma.

Elementos:

- Menu lateral;
- Projetos recentes;
- Botão criar novo projeto;
- Atividades recentes;
- Indicadores de utilização.

Fluxo principal:

Usuário entra → visualiza projetos → inicia ou continua uma criação.

# 3. Tela de Novo Projeto

## Objetivo

Iniciar uma nova história.

Elementos:

- Nome do projeto;
- Campo de ideia inicial;
- Categoria;
- Estilo visual;
- Upload de referências;
- Botão iniciar criação.

# 4. Editor de História

## Objetivo

Desenvolver a narrativa.

Elementos:

- Área de escrita;
- Assistente de IA;
- Estrutura de capítulos ou atos;
- Histórico de versões;
- Área de sugestões.

# 5. Character Studio

## Objetivo

Criar e gerenciar personagens.

Elementos:

- Lista de personagens;
- Perfil individual;
- Imagem de referência;
- Descrição física;
- Personalidade;
- Relacionamentos.

# 6. World Builder

## Objetivo

Construir o universo da história.

Elementos:

- Lista de cenários;
- Imagens de referência;
- Descrição dos locais;
- Informações de época e atmosfera.

# 7. Storyboard Studio

## Objetivo

Organizar a história visualmente.

Elementos:

- Timeline horizontal;
- Cartões de cenas;
- Miniaturas;
- Duração;
- Informações de câmera;
- Ações da cena.

# 8. Prompt Studio

## Objetivo

Preparar instruções para modelos de IA.

Elementos:

- Prompt gerado;
- Tipo de geração;
- Modelo utilizado;
- Histórico;
- Botão gerar novamente.

# 9. AI Workspace

## Objetivo

Centralizar interações inteligentes.

Elementos:

- Conversa com IA;
- Sugestões criativas;
- Histórico de solicitações;
- Controle de tarefas.

# 10. Asset Library

## Objetivo

Organizar recursos do projeto.

Elementos:

- Galeria;
- Filtros;
- Categorias;
- Visualização de arquivos.

# 11. Configurações

Elementos:

- Perfil do usuário;
- Preferências;
- Integrações;
- Configurações de IA;
- Conta.

# 12. Princípios de Navegação

A interface deve permitir que o usuário sempre saiba:

- Em qual projeto está;
- Qual etapa está executando;
- Quais elementos já foram criados;
- Qual próximo passo recomendado.

# 13. Evolução

Estes wireframes representam a primeira estrutura funcional e devem evoluir conforme testes de experiência do usuário forem realizados.

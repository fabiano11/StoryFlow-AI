# StoryFlow-AI - Prompt Mestre para Desenvolvimento

## 1. Objetivo

Este documento define as instruções principais para uma inteligência artificial ou equipe de desenvolvimento construir a plataforma StoryFlow-AI seguindo a documentação oficial do projeto.

Este arquivo deve ser utilizado junto com todos os documentos existentes na pasta `docs/`.

# 2. Papel da IA Desenvolvedora

Você atua como uma equipe completa de desenvolvimento de software composta por:

- Arquiteto de software;
- Desenvolvedor frontend;
- Desenvolvedor backend;
- Especialista em banco de dados;
- Engenheiro de inteligência artificial;
- Especialista em experiência do usuário;
- Analista de qualidade.

Sua responsabilidade é transformar a documentação do StoryFlow-AI em uma aplicação funcional, escalável e profissional.

# 3. Regra Principal

Antes de criar qualquer código:

1. Leia todos os documentos existentes no repositório;
2. Entenda a visão do produto;
3. Respeite a arquitetura definida;
4. Não crie funcionalidades fora do escopo sem aprovação.

# 4. Estratégia de Desenvolvimento

A aplicação deve ser construída por etapas:

## Etapa 1 - Fundação

Criar:

- Estrutura do projeto;
- Configuração inicial;
- Sistema de usuários;
- Banco de dados;
- Dashboard;
- Gerenciamento de projetos.

## Etapa 2 - Núcleo Criativo

Implementar:

- Histórias;
- Personagens;
- Cenários;
- Cenas;
- Storyboard.

## Etapa 3 - Inteligência Artificial

Adicionar:

- Assistente criativo;
- Geração de textos;
- Geração de prompts;
- Integrações com modelos de IA.

## Etapa 4 - Produção Visual

Adicionar:

- Imagens;
- Vídeos;
- Processos multimídia;
- Exportações.

# 5. Padrões de Código

O desenvolvimento deve seguir:

- Código limpo;
- Componentes reutilizáveis;
- Organização por módulos;
- Documentação das funções importantes;
- Boas práticas de segurança.

# 6. Interface do Usuário

A interface deve priorizar:

- Simplicidade;
- Clareza;
- Fluxo criativo intuitivo;
- Design profissional;
- Boa experiência visual.

# 7. Inteligência Artificial

As integrações de IA devem:

- Ser independentes da interface principal;
- Permitir troca de modelos;
- Registrar histórico das gerações;
- Controlar custos e utilização.

# 8. Processo de Implementação

Para cada módulo criado:

1. Analisar requisitos;
2. Criar planejamento técnico;
3. Implementar;
4. Testar;
5. Documentar;
6. Validar antes de avançar.

# 9. Critério de Qualidade

Uma funcionalidade só deve ser considerada concluída quando:

- Funcionar corretamente;
- Estiver integrada ao sistema;
- Possuir tratamento de erros;
- Estiver documentada.

# 10. Visão Final

O objetivo é construir uma plataforma profissional de criação audiovisual assistida por inteligência artificial, capaz de transformar ideias em histórias, storyboards e conteúdos visuais através de um fluxo integrado.

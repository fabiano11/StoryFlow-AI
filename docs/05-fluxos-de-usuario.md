# StoryFlow-AI - Fluxos de Usuário

## 1. Objetivo

Este documento descreve como os usuários irão interagir com a plataforma StoryFlow-AI, desde a criação de um projeto até a geração de conteúdos visuais.

O objetivo é definir a experiência esperada e orientar o desenvolvimento das interfaces e regras de negócio.

# 2. Fluxo Principal de Criação

## Etapa 1 - Entrada no Sistema

O usuário acessa a plataforma e realiza autenticação.

Após entrar, terá acesso ao Dashboard com seus projetos e atividades recentes.

## Etapa 2 - Criar Novo Projeto

O usuário inicia um novo projeto informando:

- Nome;
- Ideia inicial;
- Categoria;
- Estilo desejado;
- Referências.

O sistema cria a estrutura inicial do projeto.

## Etapa 3 - Desenvolvimento da História

O usuário pode solicitar auxílio da IA para:

- Criar conceito;
- Desenvolver narrativa;
- Definir estrutura da história;
- Criar roteiro.

O usuário poderá revisar, editar e aprovar cada etapa.

## Etapa 4 - Criação dos Personagens

A partir da história criada, o usuário desenvolve os personagens.

Fluxo:

1. Criar personagem;
2. Definir características;
3. Adicionar personalidade;
4. Inserir referências visuais;
5. Aprovar versão final.

## Etapa 5 - Construção do Universo

O usuário cria os ambientes da história:

- Locais;
- Cenários;
- Épocas;
- Elementos visuais.

A IA pode auxiliar sugerindo detalhes e referências.

## Etapa 6 - Criação do Storyboard

O roteiro é convertido em cenas visuais.

Cada cena possui:

- Sequência;
- Duração;
- Personagens envolvidos;
- Ação;
- Enquadramento;
- Movimento de câmera;
- Descrição visual.

## Etapa 7 - Geração de Prompts

O sistema transforma informações das cenas em prompts preparados para ferramentas de IA.

Tipos:

- Imagem;
- Vídeo;
- Animação.

## Etapa 8 - Produção Visual

Os conteúdos gerados são organizados dentro do projeto.

O usuário poderá:

- Comparar versões;
- Selecionar resultados;
- Ajustar prompts;
- Gerar novas versões.

## Etapa 9 - Exportação

O projeto final poderá ser exportado como:

- Roteiro;
- Storyboard;
- Apresentação;
- Material de produção.

# 3. Fluxo de Revisão

Todas as etapas devem permitir:

- Editar informações;
- Voltar etapas anteriores;
- Criar versões alternativas;
- Manter histórico.

# 4. Fluxo Colaborativo

No futuro, usuários poderão compartilhar projetos com equipes.

Possíveis permissões:

- Proprietário;
- Editor;
- Visualizador.

# 5. Princípio de Experiência

O usuário deve sempre compreender:

- Onde está dentro do projeto;
- Qual etapa está concluída;
- Qual é o próximo passo;
- Quais recursos estão disponíveis.

O fluxo deve transformar a criação de histórias em um processo organizado, intuitivo e escalável.

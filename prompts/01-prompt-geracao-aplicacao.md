# StoryFlow-AI - Prompt de Geração da Aplicação

## 1. Objetivo

Este documento contém o prompt principal para utilização em ferramentas de inteligência artificial destinadas à criação da aplicação StoryFlow-AI.

Ele deve ser utilizado junto com toda a documentação existente no repositório.

# 2. Prompt Principal

Você é uma equipe completa de desenvolvimento responsável por criar a plataforma StoryFlow-AI.

Sua função é transformar a documentação do projeto em uma aplicação funcional, profissional e escalável.

Antes de iniciar qualquer implementação:

1. Leia todos os documentos disponíveis no repositório;
2. Entenda a visão do produto;
3. Analise requisitos, arquitetura, módulos e design;
4. Planeje a implementação antes de gerar código.

# 3. Regras de Desenvolvimento

A aplicação deve:

- Seguir arquitetura modular;
- Utilizar código organizado;
- Criar componentes reutilizáveis;
- Manter separação entre frontend, backend e serviços;
- Possuir documentação clara;
- Ser preparada para evolução futura.

# 4. Ordem de Construção

A implementação deve seguir esta sequência:

## Primeira etapa

Criar:

- Estrutura inicial do projeto;
- Configuração do ambiente;
- Sistema de usuários;
- Banco de dados;
- Dashboard.

## Segunda etapa

Criar:

- Gerenciamento de projetos;
- Histórias;
- Personagens;
- Cenários;
- Cenas.

## Terceira etapa

Criar:

- Storyboard Studio;
- Prompt Studio;
- Biblioteca de recursos.

## Quarta etapa

Adicionar:

- Integrações com IA;
- Geração de conteúdo;
- Processos multimídia.

# 5. Experiência do Usuário

A interface deve transmitir:

- Criatividade;
- Tecnologia;
- Profissionalismo;
- Simplicidade.

O usuário deve conseguir criar histórias sem precisar entender detalhes técnicos.

# 6. Inteligência Artificial

As integrações de IA devem ser construídas de forma flexível.

A aplicação deve permitir:

- Troca de modelos;
- Histórico de gerações;
- Controle de custos;
- Evolução dos recursos inteligentes.

# 7. Critério de Entrega

Cada módulo desenvolvido deve possuir:

- Implementação funcional;
- Testes básicos;
- Interface integrada;
- Documentação atualizada.

# 8. Resultado Esperado

Construir uma plataforma completa onde usuários possam transformar ideias em histórias, roteiros, storyboards e conteúdos visuais utilizando inteligência artificial como ferramenta criativa.
